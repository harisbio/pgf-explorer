# PGF-Explorer

A database of genome-wide gene family identification studies in plants.

**Website:** https://harisbio.github.io/pgf-explorer/

PGF-Explorer records, for about 10,000 studies published from 2000 to 2025, what was studied (gene family, species,
number of genes), how it was studied (methods and tools, phylogeny, duplication analysis) and with what evidence
(RNA-seq, RT-qPCR and functional experiments). Each extracted value is stored with the sentence it was taken from, and
each record links to its article page.

## Pages

- **Home** (`index.html`): what the database is, key numbers, how it was built, and a first look at the literature.
- **Explorer** (`explorer.html`): a sortable, filterable table; click a title to see the full record and the sentence
  behind each value. Filters can be set from the address, for example `explorer.html?family=WRKY` or
  `explorer.html?species=Oryza%20sativa`.
- **Downloads** (`downloads.html`): the complete dataset, supporting quotes and citations for every paper.
- **About & citation** (`about.html`): scope, methods, fields, quality checks, limitations and how to cite.

## Repository structure

| Path | Contents |
|---|---|
| `index.html`, `explorer.html`, `downloads.html`, `about.html` | the four pages of the site |
| `assets/css/`, `assets/js/` | styles and scripts |
| `data/` | files generated by the build script and loaded by the site, plus the downloadable dataset |
| `raw_data/` | source records and supporting quotes the site is built from |
| `docs/data_dictionary.md` | description of every field |
| `scripts/build_database.py` | builds `data/` from `raw_data/` |
| `scripts/serve-local.mjs` | small local web server |

## Running locally

Requires [Node.js](https://nodejs.org/) 16 or later.

```bash
npm run start
```

Then open http://127.0.0.1:4173/index.html.

## Rebuilding the data

Requires Python 3 with pandas. After changing the files in `raw_data/`:

```bash
npm run build
```

## How to cite

Haris M, Azeem F, Golokhvast KS, Nawaz MA. PGF-Explorer: a database of genome-wide gene family identification studies
in plants. Version 1.0. 2026. https://harisbio.github.io/pgf-explorer/

When you use a record, please also cite the original article (see `data/pgf_explorer_citations.bib`).

Related: [extraction program](https://github.com/harisbio/Genome_wide_PDF_extractor)
([Zenodo](https://doi.org/10.5281/zenodo.24104217)) and
[meta-analysis code](https://github.com/harisbio/Meta_Analysis_Genomewide_In_silico_studies).
